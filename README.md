# Polarimeter Optical Activity Simulator

A single-file teaching simulation of a polarimeter: unpolarized light, polarizer, a sample tube of a chiral compound, and an analyzer. It shows how the two enantiomers rotate the plane of polarized light in opposite directions, and why (n_L ≠ n_R).

Open `index.html` in a browser; no build or dependencies.
